# VibeDeploy design context

VibeDeploy is an operational workspace for solo vibe coders. The visual language is a dark developer console with a lime action accent, violet AI signal, and monospace metadata. The product prioritizes scanability: projects and environments live in a narrow rail, the center is reserved for diff and activity, and the right rail holds reversible actions and checks.

- Palette: `#111114` canvas, `#19191e` surfaces, `#c7ff4d` action/success, `#b18aff` AI, `#6baeff` info.
- Typography: Manrope for interface copy, DM Mono for hashes, file paths, timestamps, and system labels.
- Interaction: risky actions use preview + explicit confirmation; success is shown by text and icon as well as color.
- Responsive: collapse the sidebar and stack operational cards below 700px.
